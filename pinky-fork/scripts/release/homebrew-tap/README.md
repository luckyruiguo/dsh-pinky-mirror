# DIYgod's Homebrew tap

```sh
brew install --cask diygod/tap/pinky
```

| Cask | |
| --- | --- |
| [`pinky`](Casks/pinky.rb) | [Pinky](https://github.com/DIYgod/pinky): let AI agents use your phone, with you in the loop. Also installs the `pinkyctl` command (`pinkyctl mcp`). |

The casks follow their apps' releases: a workflow takes the cask that each release of Pinky carries, within a quarter of an hour. Pinky updates itself, so `brew upgrade` leaves it alone unless you pass `--greedy`.
